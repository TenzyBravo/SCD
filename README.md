# The Safe Center For Development — Website

Mostly static HTML/CSS/JS, hosted on Hostinger. The **Media, Toolkits, Jobs and
Training** pages are generated by PHP from a MySQL database that staff manage in
the admin area at `/admin` (staff accounts, roles and an audit log). Setup steps
for Hostinger: [docs/ADMIN-SETUP.md](docs/ADMIN-SETUP.md).

## Structure

```
├── index.html          Home                      ┐
├── about.html          About                     │
├── focus.html          Areas of Focus            │ static pages
├── support.html        Support Units             │
├── contact.html        Contact, map, offices     │
├── thanks.html         Form confirmation         ┘
├── index.php           Front controller for the database-driven pages + /admin
├── .htaccess           Sends media.html, toolkits.html, jobs.html, training.html,
│                       media/*, uploads/* and admin/* to index.php; blocks the
│                       folders below from the web
├── app/                PHP application (Core, Controllers, Models, Views)
├── config/             config.php (defaults) + config.local.php (server only, not in git)
├── database/           schema.sql + seed.sql — import once in phpMyAdmin
├── storage/            uploads/ (photos, documents) and logs/ — back up uploads/
├── docs/               ADMIN-SETUP.md
├── css/styles.css      Full design system + dark mode
├── css/admin.css       Admin area (on top of Bootstrap 5)
├── js/main.js          Nav, theme, reveal, counters, slider, forms
├── js/admin.js         Admin area (delete confirmations)
└── assets/images/      Logo + photos
```

The public header and footer exist in every static page **and** in
`app/Views/layouts/site.php` — change both when the navigation or footer changes.

## Run locally

The static pages open in any web server, but the database-driven pages and
`/admin` need Apache (for `.htaccess`), PHP 8.1+ and MySQL/MariaDB — e.g. MAMP,
XAMPP or Laragon:

1. Create a database and import `database/schema.sql`, then `database/seed.sql`.
2. Copy `config/config.local.example.php` to `config/config.local.php` and fill
   in the database details (add `'app' => ['debug' => true]` to see errors).
3. Serve this folder as the document root and open `/admin` to create the first
   administrator account.

## Swapping in real assets

- **Logo**: replace the `<span class="brand-mark">SCD</span>` block in every HTML file's header/footer with `<img src="assets/images/logo.svg" alt="The Safe Center For Development" />`. Size ~42×42 in the header.
- **Hero image**: change the URL in `css/styles.css` under `.hero::before`.
- **Program/news photos**: swap the Unsplash `src` attributes on `.card-media img`.

## Forms

The forms (newsletter, training registration, job application, contact) still
post to FormSubmit through `initForms()` in `js/main.js`. The course and
position drop-downs are filled from the database.

## Features shipped

- Fully responsive, sticky nav with mobile drawer
- Dark mode toggle (persisted)
- Scroll reveal animations, animated counters, autoplay testimonial slider
- Partner logo marquee, back-to-top button, skip link, reduced-motion support
- Accessible forms with client-side stub submission
- SEO meta + OG tags, semantic HTML
- Google Fonts (Poppins + Inter), emerald/gold palette per brief
- Admin area: staff accounts with roles, editable permissions, account lockout, audit log; manage news, toolkits, jobs and courses
